Korean Typing 타자 연습

Korean keyboards (두벌식) put consonants on the left hand and vowels on the right. You type letter by letter and the computer stacks them into syllables: ㅎ ㅏ ㄴ → 한. Double consonants (ㄲ ㄸ ㅃ ㅆ ㅉ) and ㅒ ㅖ use Shift; ㅘ is ㅗ then ㅏ.

No Korean keyboard installed? No problem: this game reads the key positions, so your normal keyboard works (the on-screen keys show which letter each key makes). On a phone, tap the on-screen keys.
