Sentence Builder 문장 만들기

Korean puts the verb at the end: 저는 사과를 먹어요 is literally “I apple eat”. Tap the tiles in order to build the sentence. One tile is a trap with the wrong particle!

  • Subject / topic → time → place → object → verb
  • 안 and 못 go right before the verb: 고기를 안 먹어요
  • Questions keep the same order, just with a question word and a rising “?”: 어디에 가요?
